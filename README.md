# Atelier Prisma｜全息典藏展

一個單檔免建置的 3D 互動全息閃卡美術館展廳與暗箱鑑賞網頁。支援拖放、貼上（`Ctrl+V`）或點擊匯入任何自訂圖片，即時套用 15 款全息材質與分區光學浮雕特效。

## 主要特色

- **日光／夜間展廳雙模式**：預設溫潤暖白美術館牆面，可一鍵切換為帶上方射燈光暈的深邃夜間展廳；點進暗箱後固定維持深暗環境以呈現最高全息對比度。
- **15 款全息材質對照牆**：包含「典藏分區全息（Atelier Master）」與經典 8 款、原創 6 款全息材質，頂部可直接切換不同作品即時對照。
- **分區光學著色器**：即時分析原圖主色調、明暗分區與線稿梯度，支援放射太陽紋／流動水波絲綢紋／宇宙星斑微蝕刻、線稿微浮雕、自然漸層光針十字星閃、8 層金屬實體厚度與雙層空間粒子。
- **沉浸式暗箱互動**：
  - 單擊翻面、按住拖曳自由 3D 旋轉把玩（快速橫甩慣性翻面）。
  - 滾輪微距縮放（`1.0×`～`2.5×`）與放大平移檢視細節（按 `0` 或雙擊背景復位）。
  - 依進入來源自動對應 `← / →` 切換不同作品（3D 側滑轉場）或同一張圖的 15 款特效（光波掃描過渡），`↑ / ↓` 跨維度切換。
  - 右上角極簡自動隱藏控制列與退出門框圖示，內建多款裝裱外框（含「精密金屬包角」與「美術館雕花框」）與高解析 PNG 匯出。

## 快速上架至 GitHub Pages

1. 將下載的 `atelier_prisma.html` 重新命名為 `index.html`。
2. 在本倉庫首頁點選 **Add file → Upload files**，將 `index.html` 拖入並 Commit 至 `main` 分支。
3. 前往倉庫 **Settings → Pages**，將 **Source** 設為 `Deploy from a branch`，分支選擇 `main` / `/ (root)` 並儲存，稍候片刻即可透過 GitHub Pages 線上開啟展廳。
